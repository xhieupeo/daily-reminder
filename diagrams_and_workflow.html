From Morning Planning to Night Wrap-up
PHASE 1 🌅 Morning Check-in
➔

➔

PHASE 5 🌙 Night Wrap-up
➔
5. Streak Calculation & Cloud Sync Supabase Sync & Stats

Daily streak count increments. All completed session logs and task history sync securely to Supabase for multi-device continuity.

Daily Tasks / Jobs CRUD Engine

Calendar-Indexed State Store

1. CREATE (Add Job)

User enters task title in header bar or clicks any date cell on the calendar.

// Task Schema
id: "task-1730472000"
title: "Complete Calculus Chapter 4"
date: "2026-11-01" // YYYY-MM-DD
priority: "high" // 🔴 red dot
completed: false
estimatedPomodoros: 3

2. READ (Daily & Calendar Views)

Tasks are indexed by date key. Selecting any date in the calendar instantly queries tasks for that specific day.

• Filter tabs: [All], [Pending], [Completed]
• Calendar query: getTasksByDate(selectedDate)
• Month dot badges: renderBadgesForMonth(currentMonth)
• Progress calculation: (completed / total) * 100

3. UPDATE (Edit & Complete)

In-place title editing, toggle checkbox, or drag-and-drop to reschedule to another date.

• Checkbox toggle: completed = !completed
• Triggers level-up sound & pixel confetti
• Reorder tasks within day list via up/down buttons
• Reschedule: update task.date to target day

4. DELETE (Remove with Undo)

Safeguards against accidental task deletion with an instant retro undo toast bar.

• Click [X] or Trash icon
• Task removed from view immediately
• 5-second retro toast popup: "Task Deleted. [UNDO]"
• Permanent purge committed after toast expires
